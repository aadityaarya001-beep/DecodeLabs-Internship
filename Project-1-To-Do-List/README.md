# Project 1 - To-Do List Application

## DecodeLabs Python Programming Internship

This project is a command-line To-Do List application developed using Python as part of the DecodeLabs Python Programming Internship.

## Features

- Add new tasks
- View all saved tasks
- Delete tasks that are no longer needed
- Automatically assign task numbers
- Save tasks permanently using a JSON file
- Load saved tasks when the program is restarted
- Handle invalid menu choices

## Technologies Used

- Python
- JSON
- Visual Studio Code

## Project Files

- `todo.py` - Main Python program
- `tasks.json` - Stores the saved tasks

## How It Works

The program displays a menu with four options:

1. Add Task
2. View Tasks
3. Delete Task
4. Exit

The user can add, view, and delete tasks through the command-line interface. Tasks are stored in `tasks.json`, allowing them to remain available even after the program is closed and restarted.
